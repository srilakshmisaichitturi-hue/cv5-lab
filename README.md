# Edge Detection Using Sobel, Prewitt and Canny

## 1. Project Overview

Edge detection is an important technique in Digital Image Processing and Computer Vision.

An edge represents a region in an image where there is a significant change in pixel intensity. Edges are useful for identifying the boundaries and shapes of objects in an image.

In this project, three different edge detection techniques are implemented and compared:

1. Sobel Edge Detection
2. Prewitt Edge Detection
3. Canny Edge Detection

The input image is first converted into grayscale and then each edge detection method is applied to the image. Finally, the original image and the detected edge images are displayed together.

---

## 2. Objective

The main objective of this project is to understand how different edge detection operators work and how they can be implemented using Python and OpenCV.

The project helps in understanding:

- Grayscale image processing
- Image gradients
- Edge detection
- Sobel operator
- Prewitt operator
- Canny edge detection
- Image filtering
- Comparison of edge detection techniques
